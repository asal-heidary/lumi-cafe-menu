# ☕ LUMI Café Website

A modern and responsive café landing page built with **HTML5** and **CSS3**.

## 📖 About the Project

LUMI Café is a fictional café website designed to showcase a coffee shop's menu, services, and contact information in an elegant and user-friendly way.

The project focuses on creating a visually appealing interface using only HTML and CSS without any JavaScript frameworks.

## ✨ Features

* Responsive design for desktop, tablet, and mobile devices
* Fixed navigation bar with smooth scrolling
* Café introduction section
* Statistics cards section
* Product menu with coffee and dessert items
* Hover animations and interactive effects
* Modern footer with contact information
* Custom Persian font support (IRANYekan)

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries
